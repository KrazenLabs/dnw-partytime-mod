# Drag'n'Wash PartyTime Mod

Bring your own music! This mod lets you import your own songs into the game (.ogg) and the jukebox will play them in a random order. Slap the PARTY button next to it for a real party feel!

# Installation

Simply download the [latest version of the DnW Mod Manager](https://github.com/KrazenLabs/dnw-modmanager/releases/latest), which will let you install the mod directly. No separate download needed!

# Usage

You can import your songs either from the Mod Config menu (default: F10) or using the Mod Manager.

# How to uninstall

Just remove it using the Mod Manager.
